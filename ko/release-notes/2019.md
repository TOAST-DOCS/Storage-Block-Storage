## 2019. 01. 29. { #january-29-2019 }

<a id="january-29-2019-added-features"></a>
### 기능 개선/변경 { #january-29-2019-added-features }

* 블록 스토리지 생성 시 원본으로 스냅숏을 선택할 수 없도록 변경됩니다.
* 스냅숏으로 블록 스토리지 생성 시 가용성 영역과 블록 타입을 선택할 수 있도록 변경됩니다.
